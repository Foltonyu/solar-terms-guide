# 节气食光 —— 二十四节气互动养生指南

> 顺应天时，食养合一，感受千年智慧的生活美学

一款以中国水墨画美学为设计灵感的交互式网页应用，涵盖中国传统二十四节气的养生智慧。融合传统文化与现代前端技术，打造沉浸式「数字画卷」体验。

## 功能特色

- **当前节气高亮**：自动识别当前节气（如谷雨），独立展示区呈现完整信息
- **SVG 节气圆轮**：24 个节气环形排列，支持点击和悬浮提示，四季色彩编码
- **二十四节气全览**：完整收录四季二十四个节气的文化介绍、时令食材、养生建议与经典诗词
- **详情弹窗导航**：点击任意节气卡片或轮盘扇区，查看详情，支持左右箭头切换
- **四季筛选动画**：春、夏、秋、冬一键筛选，带平滑过渡效果
- **水墨画风格界面**：融合传统水墨画元素与现代交互设计
- **四季粒子特效**：春之花瓣、夏之萤火、秋之落叶、冬之飘雪
- **键盘快捷键**：← → 切换节气，Esc 关闭弹窗
- **响应式设计**：完美适配桌面（3列）、平板（2列）与手机（1列）

## 技术实现

- **纯前端**：HTML + CSS + 原生 JavaScript，零依赖
- **SVG 轮盘**：程序化生成，支持精确点击检测和悬浮提示
- **CSS 动画**：粒子特效、卡片过渡、弹窗缩放均为纯 CSS 实现
- **Google Fonts**：马善政体（Ma Shan Zheng）+ 思源宋体（Noto Serif SC）

## 使用方法

直接在浏览器中打开 `index.html` 即可体验。也可部署到任意静态托管服务。

```bash
# 本地预览
python3 -m http.server 8000
# 访问 http://localhost:8000
```
