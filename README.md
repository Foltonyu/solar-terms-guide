# 节气食光 —— 二十四节气互动养生指南

一款以中国水墨画美学为设计灵感的单页交互式网页应用，涵盖中国传统二十四节气的养生智慧。

## 功能特色

- **二十四节气全览**：完整收录春夏秋冬四季二十四个节气的文化介绍、时令食材、养生建议与经典诗词
- **节气圆轮导航**：以圆形时间轴展示全年节气，点击即可查看详情
- **自动识别当前节气**：根据当前日期自动高亮显示对应节气
- **四季筛选**：春、夏、秋、冬一键筛选，快速浏览
- **水墨画风格界面**：融合传统水墨画元素与现代交互设计
- **四季粒子特效**：春之花瓣、夏之萤火、秋之落叶、冬之飘雪
- **响应式设计**：完美适配桌面与移动端

## 技术实现

- 纯 HTML + CSS + 原生 JavaScript
- 单文件架构（`index.html`）
- 无外部依赖（仅引用 Google Fonts 字体）
- 全部视觉效果由 CSS 与 Canvas 实现，无需图片资源

## 使用方法

直接在浏览器中打开 `index.html` 即可体验。

## 字体

- **马善政体**（Ma Shan Zheng）：用于标题与节气名称
- **思源宋体**（Noto Serif SC）：用于正文内容
